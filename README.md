# jankenpo-javascript-deno
Jogo simples de pedra, papel e tesoura escrito em JavaScript para rodar no runtime Deno

## Preparação
A ideia é executar o jogo com o interpretador do runtime, então instale-o primeiro, na versão que preferir. O projeto não usa bibliotecas externas, portanto não é preciso rodar instalador de pacotes.

## Execução
Chame o runtime apontando para o arquivo de entrada do projeto.
